Конфиденциальность

Spin Sprout сохраняет ваши колёса на этом устройстве. В приложении нет аккаунтов, рекламы, инструментов аналитики или сетевых служб; во время работы оно не использует ИИ. Резервная копия устройства может содержать данные приложения. Файлы и результаты покидают приложение только по вашему выбору при экспорте или отправке.

Удалите колесо, чтобы убрать его из приложения. Экспортированными файлами и резервными копиями устройства вы управляете отдельно.

Настройки оформления сохраняются на вашем устройстве. У выбранных вами мест назначения для экспорта или отправки данных есть собственные правила конфиденциальности.

Этот сайт размещён на GitHub Pages. GitHub может обрабатывать технические данные запросов, включая ваш IP-адрес, для предоставления и защиты сайта. Это не связано с работой приложения. Если вы напишете в поддержку, мы получим ваше сообщение и указанные в нём сведения и используем их для ответа. Не отправляйте пароли или личное содержимое резервных копий. По вопросам конфиденциальности обращайтесь по указанному ниже адресу поддержки.
