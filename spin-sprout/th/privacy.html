Spin Sprout บันทึกวงล้อไว้บนอุปกรณ์นี้ แอปไม่มีบัญชี โฆษณา เครื่องมือวิเคราะห์ หรือบริการเครือข่าย และไม่ใช้ AI ขณะทำงาน ข้อมูลสำรองของอุปกรณ์อาจมีข้อมูลของแอป ไฟล์และผลลัพธ์จะออกจากแอปก็ต่อเมื่อคุณเลือกส่งออกหรือแชร์เท่านั้น

ลบวงล้อเพื่อนำออกจากแอป คุณจัดการไฟล์ที่ส่งออกและข้อมูลสำรองของอุปกรณ์แยกต่างหาก

การตั้งค่ารูปแบบการแสดงผลจะบันทึกไว้ในอุปกรณ์ของคุณ ปลายทางที่คุณเลือกเพื่อส่งออกหรือแชร์มีแนวทางความเป็นส่วนตัวของตนเอง

เว็บไซต์นี้โฮสต์บน GitHub Pages โดย GitHub อาจประมวลผลข้อมูลทางเทคนิคของคำขอ รวมถึงที่อยู่ IP ของคุณ เพื่อให้บริการและปกป้องเว็บไซต์ ซึ่งแยกจากการทำงานของแอป หากคุณส่งอีเมลถึงฝ่ายสนับสนุน เราจะได้รับข้อความและข้อมูลที่คุณใส่มา และใช้เพื่อตอบกลับ อย่าส่งรหัสผ่านหรือเนื้อหาส่วนตัวในข้อมูลสำรอง หากมีคำถามเรื่องความเป็นส่วนตัว ให้ติดต่อที่อยู่อีเมลฝ่ายสนับสนุนด้านล่าง
