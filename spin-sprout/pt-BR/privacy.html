Privacidade

O Spin Sprout salva suas roletas neste dispositivo. Não exige conta nem usa anúncios, ferramentas de análise, serviços de rede ou IA durante o funcionamento. O backup do dispositivo pode incluir dados do app. Arquivos e resultados só saem do app quando você escolhe exportar ou compartilhar.

Exclua uma roleta para removê-la do app. Você gerencia separadamente os arquivos exportados e os backups do dispositivo.

As preferências de aparência são salvas no seu dispositivo. Os destinos que você escolhe para exportar ou compartilhar têm suas próprias práticas de privacidade.

Este site é hospedado no GitHub Pages. O GitHub pode processar dados técnicos das solicitações, incluindo seu endereço IP, para fornecer e proteger o site. Isso é separado do app. Se você enviar um e-mail ao suporte, receberemos sua mensagem e as informações que incluir e as usaremos para responder. Não envie senhas nem conteúdo privado dos backups.
