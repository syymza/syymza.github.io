Spin Sprout menyimpan roda Anda di perangkat ini. Aplikasi tidak memiliki akun, iklan, alat analitik, layanan jaringan, atau AI saat digunakan. Cadangan perangkat dapat mencakup data aplikasi. File dan hasil hanya keluar dari aplikasi saat Anda memilih untuk mengekspor atau membagikannya.

Hapus roda untuk mengeluarkannya dari aplikasi. File yang diekspor dan cadangan perangkat dikelola secara terpisah oleh Anda.

Pengaturan tampilan disimpan di perangkat Anda. Tujuan yang Anda pilih untuk mengekspor atau membagikan konten memiliki kebijakan privasinya sendiri.

Situs ini dihosting di GitHub Pages. GitHub dapat memproses data teknis permintaan, termasuk alamat IP Anda, untuk menyediakan dan melindungi situs. Hal ini terpisah dari aplikasi. Jika Anda mengirim email ke dukungan, kami menerima pesan dan informasi yang Anda sertakan, lalu menggunakannya untuk membalas. Jangan kirim kata sandi atau isi pribadi dari cadangan. Untuk pertanyaan privasi, gunakan alamat dukungan di bawah.
