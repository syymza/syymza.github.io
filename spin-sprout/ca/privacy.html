Privadesa

Spin Sprout desa les teves rodes en aquest dispositiu. No té comptes, anuncis, analítica, serveis de xarxa ni IA durant l’ús. La còpia de seguretat del dispositiu pot incloure dades de l’app. Els fitxers i els resultats només surten de l’app quan decideixes exportar-los o compartir-los.

Suprimeix una roda per treure-la de l’app. Els fitxers exportats i les còpies de seguretat del dispositiu es gestionen per separat.

Les preferències d’aparença es desen al dispositiu. Les destinacions que triïs per exportar o compartir tenen les seves pròpies pràctiques de privadesa.

Aquest lloc web s’allotja a GitHub Pages. GitHub pot tractar dades tècniques de les sol·licituds, inclosa la teva adreça IP, per oferir i protegir el lloc. Aquest tractament és independent de l’app. Si escrius al servei d’assistència, rebem el missatge i la informació que hi incloguis i els fem servir per respondre’t. No enviïs contrasenyes ni contingut privat de les còpies de seguretat. Per a qüestions de privadesa, fes servir l’adreça d’assistència de sota.
