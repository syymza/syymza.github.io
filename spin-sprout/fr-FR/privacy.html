Confidentialité

Spin Sprout conserve vos roues sur cet appareil. L’app ne demande aucun compte et ne contient ni publicité, ni outil d’analyse, ni service réseau, ni IA à l’exécution. La sauvegarde de votre appareil peut inclure les données de l’app. Les fichiers et résultats ne quittent l’app que si vous choisissez de les exporter ou de les partager.

Supprimez une roue pour la retirer de l'app. Vous gérez séparément les fichiers exportés et les sauvegardes de l'appareil.

Les préférences d’apparence sont enregistrées sur votre appareil. Les destinations d’exportation ou de partage que vous choisissez appliquent leurs propres pratiques de confidentialité.

Ce site est hébergé sur GitHub Pages. GitHub peut traiter des données techniques de requête, dont votre adresse IP, pour fournir et sécuriser le site. Cela est distinct de l’app. Si vous contactez l’assistance par courriel, nous recevons le message et les informations que vous choisissez d’inclure. N’envoyez pas de mots de passe ni le contenu privé de vos sauvegardes. Nous utilisons cette correspondance pour répondre à votre demande. Pour toute question de confidentialité, utilisez l’adresse ci-dessous.
