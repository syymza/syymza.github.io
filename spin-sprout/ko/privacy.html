Spin Sprout 앱은 돌림판을 이 기기에 저장합니다. 계정, 광고, 분석 도구, 네트워크 서비스가 없으며 실행 중에 AI를 사용하지 않습니다. 기기 백업에 앱 데이터가 포함될 수 있습니다. 파일과 결과는 사용자가 내보내기나 공유를 선택할 때만 앱 밖으로 나갑니다.

돌림판을 삭제하면 앱에서 제거됩니다. 내보낸 파일과 기기 백업은 별도로 관리해야 합니다.

화면 모드 설정은 기기에 저장됩니다. 내보내기나 공유 대상으로 선택한 곳에는 해당 대상의 개인정보 처리방침이 적용됩니다.

이 웹사이트는 GitHub Pages에서 호스팅됩니다. GitHub는 사이트를 제공하고 보호하기 위해 IP 주소를 비롯한 기술적 요청 데이터를 처리할 수 있습니다. 이는 앱과 별개입니다. 지원팀에 이메일을 보내면 메시지와 포함한 정보를 받아 답변에 사용합니다. 비밀번호나 백업의 비공개 내용을 보내지 마세요. 개인정보 관련 문의는 아래 지원 주소로 보내 주세요.
