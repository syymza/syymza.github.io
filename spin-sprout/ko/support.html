돌림판 만들기

입력 또는 붙여넣기 · 한 줄에 하나씩

서로 다른 선택지 2~100개. 쉼표는 선택지 안에 그대로 남습니다.

한 번 고르기

돌릴 때마다 모든 선택지를 사용합니다. 같은 선택지가 다시 나올 수 있어요.

그룹 라운드

선택된 항목은 후보에서 빠집니다. 앱을 닫은 뒤에도 나중에 라운드를 이어갈 수 있어요.

변경 사항을 저장하면 새 라운드가 시작되고 마지막 결과가 지워집니다. 취소하면 현재 진행 상황이 유지됩니다.

가중치 사용

가중치가 2인 선택지는 1인 선택지보다 선택될 확률이 두 배입니다. 라운드에서 하나를 고를 때마다 확률이 갱신됩니다.

선택지는 서로 다르고 비어 있지 않아야 하며 100자 이내여야 합니다. 가중치는 1~100으로 설정하세요.

돌림판 보관하기

JSON 백업에는 선택지, 가중치, 라운드 진행 상황이 포함됩니다. 가져오면 사본이 추가되고 기존 돌림판은 유지됩니다.

설정

설정 → 백업 내보내기 / 백업 가져오기

버전 1.1 · 언어

이 앱의 iOS 설정을 열고 언어를 선택하세요. 언어를 바꾸면 iOS가 앱을 다시 시작할 수 있습니다.

iOS 18+: iOS가 설정의 첫 화면을 열면 앱 → Spin Sprout → 언어로 이동하세요.

언어가 보이지 않으면 설정 → 일반 → 언어 및 지역에서 선호하는 언어를 하나 더 추가한 뒤 돌아오세요.

돌림판을 확인하세요

돌림판 이름은 100자 이내로 입력하세요.

선택지를 2~100개 추가하세요.

선택지는 서로 다르고 비어 있지 않아야 하며 100자 이내여야 합니다. 가중치는 1~100으로 설정하세요.

2 MB보다 작은 돌림판 백업을 선택하세요.

보관함이 백업 크기 제한인 2 MB를 초과합니다. 일부 선택지나 돌림판을 제거하세요.

“저장된 파일을 읽을 수 없습니다. 원본은 보존되었습니다. 설정에서 원본 파일을 내보낼 수 있습니다.”

읽을 수 없는 파일을 보호하기 위해 저장이 일시 중지되었습니다. 먼저 설정에서 원본을 내보내세요.

읽을 수 없는 저장 파일을 대체할까요? 원본을 보관하려면 먼저 내보내세요. 빈 보관함으로 새로 시작합니다.
