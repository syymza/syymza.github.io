സ്വകാര്യത

Spin Sprout നിങ്ങളുടെ ചക്രങ്ങൾ ഈ ഉപകരണത്തിൽ സൂക്ഷിക്കുന്നു. അക്കൗണ്ടുകൾ, പരസ്യങ്ങൾ, ഉപയോഗ വിശകലനം, നെറ്റ്‌വർക്ക് സേവനം എന്നിവയില്ല; പ്രവർത്തിക്കുമ്പോൾ AI ഉപയോഗിക്കുന്നില്ല. ഉപകരണത്തിന്റെ ബാക്കപ്പിൽ ആപ്പിന്റെ ഡാറ്റ ഉണ്ടായേക്കാം. നിങ്ങൾ കയറ്റുമതി ചെയ്യാനോ പങ്കിടാനോ തിരഞ്ഞെടുക്കുമ്പോൾ മാത്രമേ ഫയലുകളും ഫലങ്ങളും ആപ്പിന് പുറത്തേക്ക് പോകൂ.

ഇല്ലാതാക്കിയാൽ ചക്രം ആപ്പിൽ നിന്ന് നീങ്ങും. കയറ്റുമതി ചെയ്ത ഫയലുകളും ഉപകരണത്തിന്റെ ബാക്കപ്പുകളും നിങ്ങൾ പ്രത്യേകം കൈകാര്യം ചെയ്യുന്നു.

രൂപഭാവവുമായി ബന്ധപ്പെട്ട മുൻഗണനകൾ നിങ്ങളുടെ ഉപകരണത്തിൽ സൂക്ഷിക്കുന്നു. കയറ്റുമതിക്കോ പങ്കിടലിനോ നിങ്ങൾ തിരഞ്ഞെടുക്കുന്ന ഇടങ്ങൾക്ക് അവയുടേതായ സ്വകാര്യതാ രീതികളുണ്ട്.

ഈ വെബ്‌സൈറ്റ് GitHub Pages-ലാണ് ഹോസ്റ്റ് ചെയ്തിരിക്കുന്നത്. സൈറ്റ് ലഭ്യമാക്കാനും സംരക്ഷിക്കാനും GitHub നിങ്ങളുടെ IP വിലാസം ഉൾപ്പെടെയുള്ള അഭ്യർത്ഥനകളുടെ സാങ്കേതിക ഡാറ്റ പ്രോസസ് ചെയ്തേക്കാം. ഇത് ആപ്പിൽ നിന്ന് വേറിട്ടതാണ്. സഹായത്തിനായി ഇമെയിൽ അയച്ചാൽ നിങ്ങളുടെ സന്ദേശവും അതിൽ നൽകിയ വിവരങ്ങളും ഞങ്ങൾക്ക് ലഭിക്കും; മറുപടി നൽകാൻ അവ ഉപയോഗിക്കും. പാസ്‌വേഡുകളോ ബാക്കപ്പിലെ സ്വകാര്യ ഉള്ളടക്കമോ അയയ്ക്കരുത്. സ്വകാര്യതയെക്കുറിച്ചുള്ള ചോദ്യങ്ങൾക്ക് താഴെയുള്ള സഹായ വിലാസത്തിൽ ബന്ധപ്പെടുക.
